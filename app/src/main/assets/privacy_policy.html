Aura TV Launcher

Privacy Policy • Last Updated: August 12, 2026

1. Introduction

Welcome to Aura TV Launcher ("we," "our," or "us"). We are committed to protecting your privacy and ensuring you have a secure, efficient, and customizable experience on your smart TV and Android-based streaming devices. This Privacy Policy details how we handle information in our application.

2. Data We Process Locally

Aura TV Launcher operates primarily as a local-first user interface. Your settings, organization folders, categories, background wallpaper configurations, and custom hotkeys are stored locally on your device via an encrypted secure database (SQLite / Room).

We process the following information strictly on your hardware:

  • Installed Application List: To display your applications on the launch grid and group them into categories. This list never leaves your device.
  • User Preferences: Column counts, aspect ratios, background theme choices, screen timeout states, and custom categories.
  • Secure Vault Details: Hidden application configurations are strictly safeguarded using local passwords without cloud sync.

3. Third-Party Services & Cloud Telemetry

To improve stability, diagnose system performance, and analyze navigation usability, Aura TV Launcher may integrate optional analytics tools if configured on your device framework:

  • Firebase Analytics & Crashlytics: Used to monitor application load times, button-clicks, and record code stacktraces during unexpected crashes. These elements are transmitted securely to Google servers and do not contain personally identifiable information (PII).
  • Firebase Remote Config: Periodically requests configuration parameters (e.g., dynamic banner definitions or feature availability) to improve remote TV setups.

4. User Permissions

To function seamlessly as a system-wide launcher, Aura TV Launcher may request specific system permissions:

  • Query All Packages: Necessary to read the list of installed applications so you can launch them directly.
  • Internet Access: Required only for downloading dynamic Remote Config structures, telemetry reports, and updating streaming category icons.

5. Your Controls & Data Deletion

Because we respect user autonomy, you can fully control your data lifecycle at any time:

  • Reset Settings: You can completely wipe the Room database, resetting all launcher categories and restoring defaults in the Settings Sidebar.
  • Application Uninstallation: Uninstalling the launcher will completely delete all local cache, categories, configuration details, and wallpaper selections from your Android OS memory space.
